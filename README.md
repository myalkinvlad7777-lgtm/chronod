# Chrono Sand (Хроно-песок)

Мод для Minecraft (Fabric), добавляющий декоративный светящийся блок «Хроно-песок» (`chronod:chronod_block`) для дальних островов Энда. Блок ведёт себя как песок (падает без опоры), слабо светится, прочнее обычного песка и показывает игроку время суток при клике пустой рукой.

Проект выполнен в рамках дисциплины «Инструментальные средства разработки программного обеспечения», команда «Хроно-песок».

## Совместимость

| Компонент | Версия |
|-----------|--------|
| Minecraft | 1.21 |
| Fabric Loader | 0.19.5 или новее |
| Fabric API | 0.102.0+1.21 |
| Java | 21 |

## Установка

1. Установите Fabric Loader для Minecraft 1.21 (официальный установщик Fabric, профиль `fabric-loader-1.21`).
2. Скачайте Fabric API 0.102.0+1.21 и файл мода `chronod-1.0.0.jar`.
3. Положите оба JAR-файла в папку `mods` игры (`%APPDATA%\.minecraft\mods` в Windows).
4. Запустите игру с профилем Fabric 1.21.
5. Проверка: в творческом режиме откройте вкладку «Строительные блоки» — в её конце должен быть «Хроно-песок».

## Использование

### Получение

- Творческий режим: вкладка «Строительные блоки» (последний предмет) или команда `/give @s chronod:chronod_block`.
- Выживание: крафт в верстаке (см. «Рецепт»).
- Добыча: блок выпадает только при разрушении алмазной или незеритовой лопатой.

### Свойства объекта

- Прочность strength(3.0, 6.0) — копается дольше обычного песка (0.5), устойчив к взрывам как камень.
- Светимость luminance 8 — блок слабо светится и заметен на тёмных островах Энда.
- requiresTool + теги mineable/shovel и needs_diamond_tool — добывается только алмазной (или незеритовой) лопатой, иначе ничего не выпадает.
- Физика обычного песка: падает, если под ним нет опоры.

### Рецепт

Форменный рецепт в верстаке: 4 песка крестом вокруг жемчуга Края → 1 хроно-песок. Жемчуг Края добывается в Энде/у эндерменов, поэтому блок «дороже» обычного песка, что соответствует его свечению и повышенной прочности.

```
 . П .
 П Ж П      П — песок, Ж — жемчуг Края
 . П .
```

### Дополнительное поведение

Сценарий: 1) Исходное состояние: в мире стоит блок хроно-песка, у игрока пустая основная рука. 2) Действие: игрок нажимает ПКМ по хроно-песку. 3) Ожидаемый результат: в чате сообщение «Хроно-песок: время мира N (день/ночь)». Для обычного песка и других блоков сообщения нет; с блоком в руке хроно-песок ведёт себя как обычный блок (к нему можно приставлять блоки).

## Сборка из исходников

Требуется JDK 21. В корне репозитория:

```powershell
.\gradlew.bat clean build
```

Готовый мод: `build/libs/chronod-1.0.0.jar` (файл `chronod-1.0.0-sources.jar` содержит исходники и для игры не нужен).
Запуск игры с модом для разработки: `.\gradlew.bat runClient`.

## Структура проекта

- `src/main/java` — исходный код мода на Java (пакет `chrono.chronod`: точка входа `Chronod`, класс регистрации `ModBlocks`).
- `src/main/resources` — ресурсы: конфигурация `fabric.mod.json`, иконка, текстуры, модели, состояния блока, локализация (`assets/chronod`) и данные: таблица добычи, рецепт, структуры (`data/chronod`), теги инструментов (`data/minecraft/tags`).
- `src/client/java` — клиентский код (точка входа клиента и генератор данных).
- `build.gradle`, `gradle.properties`, `settings.gradle` — сценарий и параметры сборки Gradle.

## Известные ограничения

- Нет естественной генерации на островах Энда: структуры `heap_chrono_sand_*.nbt` лежат в ресурсах (`data/chronod/structure`), но не подключены к генерации мира.
- Свечение постоянное и не зависит от времени суток.
- Поддерживается только Minecraft 1.21.
